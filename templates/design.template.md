## Layout Rules
### Resident screens (mobile-first)
Bottom navigation, sorting guide search, photo scan, QR bag card, history list, points.
### Collector screens (mobile-first, one-handed use outdoors)
Camera scan view, matched unit label, category picker, large number keys for kg, confirmation state.
### Admin dashboard (laptop-first, still readable on a phone)
Summary cards, charts by township / category / month, sample-data labels.

## Accessibility Basics
- readable contrast
- visible focus states where possible
- buttons/inputs have clear labels
- no tiny tap targets

## Anti-Slop Rules
- no fake logos and no Sime Darby Property logos or brand assets
- every screen shows a small "Concept prototype · sample data" label
- no fake testimonials
- no fake stats unless clearly marked sample
- no lorem ipsum in final proof
- no random gradient blobs unless they match the direction
- one clear primary action
- readable on phone width

## Design Verification Checklist
- [ ] The first screen matches the intended mood.
- [ ] The layout supports the user goal.
- [ ] Mobile width is readable.
- [ ] Nothing clones another brand.
- [ ] The build avoids fake claims and generic AI decoration.
